### 🎮 What I build

My passion is helping others succeed in business through professional communication — and I do that through code: game systems, tools, and networked backends.

- **Clan System** — server-authoritative clan, chat, and voice system for Unity 6 on Unity Gaming Services. Cloud Code owns every mutation; Cloud Save and Vivox back clans, roles, invites, moderation, text and voice.
- **Fruit Ninja VR** — VR app built on Unity's XR Interaction Toolkit, centered on immersive slicing interactions.
- **Narrative Unity Game** — branching-story game using the Fungus scripting library; player choices shape the world.
- **HackNet: Urban Anarchy** — open-world hacker game in Unreal Engine Blueprints, set in a neon-drenched cyberpunk city.
- **Stellar Sands** — 2D side-scroller in C++ with SFML: run, jump, crouch, and obstacle platforming.
- **The Green Python** — a classic Snake game rebuilt with Pygame.
